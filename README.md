# AvidusCore NetTest

Windows launcher for invited NetTest players. Install the launcher once; it downloads and updates the game for you.

## Download

[Download AvidusCore Launcher for Windows](https://github.com/BKungBK/AvidusCore/releases/latest/download/AvidusCoreLauncher-Setup-0.1.0.exe)

Run the installer, open **AvidusCore Launcher**, and choose **Install**. The launcher downloads the current game build and starts it through EOS Bootstrapper.

## Release files

Game packages and update manifests are attached to [GitHub Releases](https://github.com/BKungBK/AvidusCore/releases). Only download the launcher installer above; the launcher handles the game package and updates.
